## Method Details

### `loadFen(fen, p?)`

> 🔄 **Triggers UI refresh**

Loads a **fen position**.

`skipFenValidation = true` skips the fen validation. This should only be used if the fen is known to pass the fen tests of `isepic-chess.js` or the fen was generated by `isepic-chess.js`.

`keepOptions = true` can be used to prevent the overwrite of `board.isRotated`, `board.promoteTo` and `board.isHidden` to their respectives defaults.

The Boolean options (`skipFenValidation` and `keepOptions`) default to `false` when not set to a Boolean value of `true`.

Successfully loading a fen will set `"*"` to `board.manualResult`.

<details>
<summary><strong>Parameters</strong></summary>

- `fen` `(String)`
- `p` `(Object)` — *optional*
  - `skipFenValidation` `(Boolean)` — *optional*
  - `keepOptions` `(Boolean)` — *optional*

</details>

**Returns:**

- ✅ *On success:*
  - `Boolean`
- ⚠️ *On error:*
  - `Boolean` — `false`

**Examples:**

```javascript
board.loadFen("r1bqkbnr/pppp2pp/2n2p2/4p3/2B1P3/5N2/PPPP1PPP/RNBQ1RK1 b kq - 1 4") //true
board.loadFen("2k5/8/1K1R4/8/8/8/8/8 b - - 0 1", {keepOptions: true}) //true
board.loadFen("0invalidfen0") //false
```

> ⚠️ **Outputs an error to the console when:**
> - `fen` is an **invalid fen**.

### `playMove(mov, p?)`

> 🔄 **Triggers UI refresh**

Generates and returns a **move**.

`isMockMove = true` plays the move on a **temporal board** instead of affecting the **board**.

`isLegalMove = true` skips the legal move validation. This should only be used if the move is known to be a legal move for a specific fen and the current board fen matches it.

`isInanimated = true` prevents the **piece animation** in UI (the UI refresh takes place normally).

`playSounds = true` plays the move with **sound effects** in UI.

`isUnreferenced = true` means that the returned **move** will not be referenced (modifying these unreferenced copies will not affect the corresponding elements in the **move list** or the other way around).

The Boolean options (`isMockMove`, `isLegalMove`, `isInanimated`, `playSounds` and `isUnreferenced`) default to `false` when not set to a Boolean value of `true`.

`promoteTo` takes precedence over everything when specified and a pawn promotion takes place.

`delimiter` is a single character to look for in **moveJoined** (like `"-" in "a2-a4"`) to allow the use of any delimiters. Defaults to `"-"` if not specified.

Successfully playing a move will set `"*"` to `board.manualResult`.

<details>
<summary><strong>Parameters</strong></summary>

- `mov`
  - **moveSan** `(String)`
  - **moveUci** `(String)`
  - **moveJoined** `(String)`
  - **moveFen** `(String)`
  - **moveFromTo** `(Array)`
  - **move** `(Object)`
- `p` `(Object)` — *optional*
  - `isMockMove` `(Boolean)` — *optional*
  - `promoteTo` — *optional*
    - **squareBal** `(String)`
    - **squareAbsBal** `(String)`
    - **squareVal** `(Number)`
    - **squareAbsVal** `(Number)`
    - **squareClassName** `(String)`
    - **square** `(Object)`
  - `delimiter` `(String)` — *optional*
  - `isLegalMove` `(Boolean)` — *optional*
  - `isInanimated` `(Boolean)` — *optional*
  - `playSounds` `(Boolean)` — *optional*
  - `isUnreferenced` `(Boolean)` — *optional*

</details>

**Returns:**

- ✅ *On success:*
  - **move** `(Object)`
- ⚠️ *On error:*
  - `null`

**Examples:**

```javascript
board.playMove("Nc3") //Object{...}
board.playMove("b1_c3", {delimiter: "_"}) //Object{...}
board.playMove("0invalidmove0") //null
```

**See also:** [move properties](https://github.com/ajax333221/isepic-chess/blob/master/docs/move-properties.md#move-properties)

### `playMoves(movArray, p?)`

> 🔄 **Triggers UI refresh**

It tries to play all the moves consecutively and tells you if all moves were successfully played or not.

`isMockMove = true` plays the moves on a **temporal board** instead of affecting the **board**.

> [!TIP]
> When **isMockMove** is used, all the moves are expected to be from the active side (do not alternate them with the non-active side as the moves will not be being played). However, it is preferred to validate multiple moves with `board.isLegalMove(...)` and a loop with early break.

`isLegalMove = true` skips the legal move validation. This should only be used if the moves are known to be legal moves for a specific fen and the current board fen matches it.

`isInanimated = true` prevents the **piece animations** in UI (the UI refresh takes place normally).

`playSounds = true` plays the moves with **sound effects** in UI.

The Boolean options (`isMockMove`, `isLegalMove`, `isInanimated` and `playSounds`) default to `false` when not set to a Boolean value of `true`.

`promoteTo` takes precedence over everything when specified and a pawn promotion takes place.

`delimiter` is a single character to look for in **moveJoined** (like `"-" in "a2-a4"`) to allow the use of any delimiters. Defaults to `"-"` if not specified.

Successfully playing all moves will set `"*"` to `board.manualResult`.

<details>
<summary><strong>Parameters</strong></summary>

- `movArray` `(Array)`
- `p` `(Object)` — *optional*
  - `isMockMove` `(Boolean)` — *optional*
  - `promoteTo` — *optional*
    - **squareBal** `(String)`
    - **squareAbsBal** `(String)`
    - **squareVal** `(Number)`
    - **squareAbsVal** `(Number)`
    - **squareClassName** `(String)`
    - **square** `(Object)`
  - `delimiter` `(String)` — *optional*
  - `isLegalMove` `(Boolean)` — *optional*
  - `isInanimated` `(Boolean)` — *optional*
  - `playSounds` `(Boolean)` — *optional*

</details>

**Returns:**

- ✅ *On success:*
  - `Boolean`
- ⚠️ *On error:*
  - `Boolean` — `false`

**Examples:**

```javascript
board.playMoves(["e4", "e7-e5", "Nf3"]) //true
board.playMoves(["e2_e4", "e5", "Nf3"], {delimiter: "_"}) //true
board.playMoves(["0invalidmove0"]) //false
```

### `toggleIsRotated(newIsRotated?)`

> 🔄 **Triggers UI refresh**

Toggles (or sets) the **board property** of `board.isRotated`.

When a Boolean is passed, `board.isRotated` will be setting that specific value instead of toggling.

<details>
<summary><strong>Parameters</strong></summary>

- `newIsRotated` `(Boolean)` — *optional*

</details>

**Returns:**

- `Boolean`

**Examples:**

```javascript
board.toggleIsRotated() //true
board.toggleIsRotated(false) //true
board.toggleIsRotated(true) //true
```

---

### `setPromoteTo(qal)`

> 🔄 **Triggers UI refresh**

Changes the **board property** of `board.promoteTo`.

Min and max inclusive limits of `2` (knight) and `5` (queen) will be enforced.

**Falsy-values** and invalid inputs will default to `5` (queen).

<details>
<summary><strong>Parameters</strong></summary>

- `qal`
  - **squareBal** `(String)`
  - **squareAbsBal** `(String)`
  - **squareVal** `(Number)`
  - **squareAbsVal** `(Number)`
  - **squareClassName** `(String)`
  - **square** `(Object)`

</details>

**Returns:**

- `Boolean`

**Examples:**

```javascript
board.setPromoteTo(3) //true
board.setPromoteTo("q") //true
board.setPromoteTo("N") //true
```

### `getSquare(qos, p?)`

Returns a **square**.

If the **square** is invalid (before or after shifting by `rankShift` and `fileShift`), then `null` will be returned.

`isUnreferenced = true` means that the returned **square** will not be referenced (updates made to the **board** do not affect these unreferenced copies or the other way around).

<details>
<summary><strong>Parameters</strong></summary>

- `qos`
  - **squareBos** `(String)`
  - **squarePos** `(Array)`
  - **square** `(Object)`
- `p` `(Object)` — *optional*
  - `rankShift` `(Number)` — *optional* — `-7 to 7`
  - `fileShift` `(Number)` — *optional* — `-7 to 7`
  - `isUnreferenced` `(Boolean)` — *optional*

</details>

**Returns:**

- ✅ *On success:*
  - **square** `(Object)`
- ⚠️ *On error:*
  - `null`

**Examples:**

```javascript
board.getSquare("e4") //Object{...}
board.getSquare("a1", {rankShift: -7, fileShift: 7}) //Object{...}
board.getSquare("0invalidsquare0") //null
```

**See also:** [square properties](https://github.com/ajax333221/isepic-chess/blob/master/docs/square-properties.md#square-properties)

### `isLegalMove(mov, p?)`

Test to see if a move is legal or not.

`delimiter` is a single character to look for in **moveJoined** (like `"-" in "a2-a4"`) to allow the use of any delimiters. Defaults to `"-"` if not specified.

<details>
<summary><strong>Parameters</strong></summary>

- `mov`
  - **moveSan** `(String)`
  - **moveUci** `(String)`
  - **moveJoined** `(String)`
  - **moveFen** `(String)`
  - **moveFromTo** `(Array)`
  - **move** `(Object)`
- `p` `(Object)` — *optional*
  - `delimiter` `(String)` — *optional*

</details>

**Returns:**

- ✅ *On success:*
  - `Boolean`
- ⚠️ *On error:*
  - `Boolean` — `false`

**Examples:**

```javascript
board.isLegalMove("Nf3") //true
board.isLegalMove("g1f3") //true
board.isLegalMove("g1-f3") //true
board.isLegalMove("g1_f3", {delimiter: "_"}) //true
board.isLegalMove("0invalidsan0") //false
```

### `legalMoves(initialQos, p?)`

Returns a **final bos array** with all the squares that a piece from an **initial qos** square can legally move to.

Passing an **initial qos** square with a **square val** of `0` or a **non active sign** will result in a `[]`.

`returnType` accepted values: `"joined"`, `"fromToSquares"`, `"fen"`, `"san"`, `"uci"` and `"toSquare"`. Defaults to `"toSquare"` if not specified.

`squareType` accepted values: `"square"`, `"pos"` and `"bos"`. Defaults to `"bos"` if not specified.

<details>
<summary><strong>Parameters</strong></summary>

- `initialQos`
  - **squareBos** `(String)`
  - **squarePos** `(Array)`
  - **square** `(Object)`
- `p` `(Object)` — *optional*
  - `returnType` `(String)` — *optional*
  - `squareType` `(String)` — *optional*
  - `delimiter` `(String)` — *optional*

</details>

**Returns:**

- ✅ *On success:*
  - **finalBosArray** `(Array)`
- ⚠️ *On error:*
  - `Array` — `[]`

**Examples:**

```javascript
board.legalMoves("b1") //["c3", "a3"]
board.legalMoves("a3") //[]
board.legalMoves("0invalidsquare0") //[]
```
